# CR-010 手动测试用例

## 准备

1. `python3 -m http.server 18083` 启动本地服务
2. 浏览器打开 `http://localhost:18083/demo.html`
3. 把 ClickAsk 拖到书签栏

## 用例 1：中文 locale 中文请求

| 步骤 | 预期 |
|------|------|
| 浏览器语言设为 `zh-CN`，访问 demo.html，点 ClickAsk | 面板出现 |
| 选中任意元素 | 元素被高亮 |
| 在 `.ca-intent` 输入「帮我总结一下这页内容」 | `.ca-recommendation` 显示「推荐: 总结内容」|
| 输入「这里为什么数字下降这么多」 | 推荐变为「分析原因」|
| 输入「页面崩溃了，怎么修」 | 推荐变为「排查问题」|

## 用例 2：英文 locale 英文请求

| 步骤 | 预期 |
|------|------|
| 浏览器语言切到 `en-US`，重新激活 ClickAsk | 面板英文显示 |
| 输入 `please give me a brief recap` | `.ca-recommendation` 显示 `Recommended: Summarize` |
| 输入 `why did this number drop so much` | 显示 `Recommended: Analyze cause` |
| 输入 `the page crashed, please debug` | 显示 `Recommended: Debug issue` |

## 用例 3：跨语言半权重 fallback

| 步骤 | 预期 |
|------|------|
| 浏览器语言 `en-US`，激活 ClickAsk | 面板英文显示 |
| 输入「崩溃 崩溃」（纯中文，仅 zh debug 桶有） | 仍可被识别为 `Recommended: Debug issue`（fallback 半权重命中） |
| 浏览器语言 `zh-CN`，重新激活 ClickAsk | 面板中文显示 |
| 输入 `crash crash` | 仍可被识别为「推荐: 排查问题」|

## 用例 4：i18n 拆分回归（不破坏现有行为）

| 步骤 | 预期 |
|------|------|
| zh 模式下选元素 + 输入需求 + 切手动模板（debug） | preview 标题为「# 页面问题排查」|
| en 模式下选元素 + 输入需求 + 切手动模板（debug） | preview 标题为 `# Page Issue Debugging` |
| 关闭并重开面板，重复多次 | 文案、模板、推荐一致，无 undefined |
| 截图按钮（CR-007） / CSP banner（CR-009） / Shadow DOM（CR-008） | 全部沿用对应 locale 文案 |
