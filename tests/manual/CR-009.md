# CR-009 手动测试用例

## 准备

1. `python3 -m http.server 18082` 启动本地服务
2. 浏览器打开 `http://localhost:18082/`，把 ClickAsk 拖到书签栏

## 用例 1：本地页面正常路径（不应触发降级）

| 步骤 | 预期 |
|------|------|
| 在 `demo.html` 点击 bookmarklet | 面板正常出现在右上 |
| 检查 DOM 是否含 `.ca-csp-banner` | **不存在**（CSS 注入成功） |

## 用例 2：严格 CSP 站点降级 banner（生产验证）

需要部署到 `clickask.tedxiong.com` 后再测。

| 步骤 | 预期 |
|------|------|
| 打开 `https://github.com/<任意项目>` | 页面加载 |
| 点击 ClickAsk bookmarklet | 一段时间内左下角出现红色 banner |
| banner 文本 | 中文："本页面的 CSP 限制了样式注入，ClickAsk 已进入降级模式..." 或英文版 |
| 点 banner 的「知道了 / Got it」按钮 | banner 消失 |
| 面板本身 | 仍可用（粗糙样式），能选择元素和复制 prompt |
| Console 应有 `[Report Only]` 或 `Refused to apply inline style` 日志 | 是 |

替代验证站点：`https://twitter.com`、`https://stripe.com`。

## 用例 3：destroy 时清理 banner

| 步骤 | 预期 |
|------|------|
| 在用例 2 出现 banner 之后，点面板的关闭按钮 | banner 与面板同时消失，DOM 中 `.ca-csp-banner` 不存在 |

## 用例 4：install 页 FAQ 文案

| 步骤 | 预期 |
|------|------|
| 打开 `http://localhost:18082/` | 看到三步卡片下方多出一个 card |
| 卡片标题 | 中文「部分网站可能受限」/ 英文 "Some sites limit ClickAsk" |
| 卡片内容 | 提到 CSP / GitHub / Twitter |

## 用例 5：浏览器 console 手动触发 banner（无需真 CSP 头）

打开 demo.html，激活 ClickAsk 后在 console 跑：

```js
const e = new Event("securitypolicyviolation");
Object.defineProperty(e, "violatedDirective", { value: "style-src-elem" });
document.dispatchEvent(e);
```

预期：左下出现降级 banner。
