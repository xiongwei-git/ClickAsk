# CR-008 手动测试用例

## 1. 基础 web component

1. 在浏览器 console 临时注入：
   ```js
   class MyCard extends HTMLElement {
     constructor() {
       super();
       this.attachShadow({ mode: "open" }).innerHTML = `
         <style>.title { font-size: 20px; color: #4f46e5; }</style>
         <div class="title">Hello shadow</div>
         <p class="desc">Inside the shadow root</p>
       `;
     }
   }
   customElements.define("my-card", MyCard);
   document.body.appendChild(document.createElement("my-card"));
   ```
2. 启动 ClickAsk，hover 到 "Hello shadow" 文字上
3. **预期**：
   - hoverBox 框出 `.title` 而不是整个 `<my-card>`
   - 点击后 panel 标签显示 `.title`
   - 复制 prompt → 内含 `selector: \`my-card >>> div`，`shadowPath: \`my-card ::shadow\``

## 2. 嵌套 shadow

1. console：
   ```js
   class Outer extends HTMLElement {
     constructor() {
       super();
       this.attachShadow({ mode: "open" }).innerHTML = "<my-card></my-card>";
     }
   }
   customElements.define("my-outer", Outer);
   document.body.appendChild(document.createElement("my-outer"));
   ```
2. 点击最内层 `.title`
3. **预期**：selector 含两个 ` >>> `，`shadowPath` 含 `my-outer > my-card ::shadow`

## 3. closed shadow root 降级

1. console：
   ```js
   const host = document.createElement("div");
   host.id = "secret-host";
   const root = host.attachShadow({ mode: "closed" });
   root.innerHTML = '<button>secret</button>';
   document.body.appendChild(host);
   ```
2. ClickAsk 中点击 `#secret-host` 区域
3. **预期**：选中的是 `<div id="secret-host">`（host），不报错；prompt 不含 `>>>` / `shadowPath`（因为外部无法看到 shadow tree）

## 4. 框选含 shadow 内元素

1. 注入两个 my-card
2. 拖框覆盖两个组件
3. **预期**：标签栏显示多个元素，包含 shadow tree 内可见的有意义节点

## 6. 回归（light DOM 不应受影响）

1. 在普通 `<button id="x">` 上选中
2. **预期**：`selector: #x`，`xpath: //*[@id="x"]`，无 `shadowPath` 字段
