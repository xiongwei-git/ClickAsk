# CR-002 手动测试

环境：Chrome / Safari 最新版，按 `tests/manual/README.md` 通用前置。

| # | 步骤 | 预期 |
|---|------|------|
| 1 | demo.html 打开 ClickAsk，点击状态指示器（带圆点的"就绪"） | 圆点变灰，状态文字变"已暂停" |
| 2 | 再点一次 | 恢复"就绪"，圆点呼吸动画恢复 |
| 3 | 按住 Alt，点击 `Retry sync` 按钮 | 按钮的原 onclick 正常触发（console 中看 framework warning 等） |
| 4 | 松开 Alt，再次点击销售表某行 | 正常出现红色选框 |
| 5 | 按住 Alt 滚动页面 | 滚动正常，hover-box 隐藏，不阻断滚动 |
| 6 | 按住 Alt 框选拖拽 | 不出现 marquee 虚线框 |
| 7 | Tab 键聚焦到状态按钮 | 看到 focus 轮廓，回车切换暂停 |
