# CR-001 手动测试

环境：Chrome / Safari 最新版，本地启动 `python3 -m http.server 18081`，
按 `tests/manual/README.md` 的"通用前置"装好书签。

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 打开 demo.html，点击书签 | 面板右下角出现，最下方有 5 个灰色不可点击的 AI 按钮 |
| 2 | 点击销售表中"East China"那一行 | 行被红框选中，5 个 AI 按钮变亮 |
| 3 | 点击 ChatGPT 按钮 | 浏览器打开新标签 `chat.openai.com`，剪贴板已是完整 prompt |
| 4 | 切到 ChatGPT 标签，⌘V 粘贴 | Markdown prompt 被完整粘贴 |
| 5 | 关闭新标签，回到 demo，按 Esc 清空选区 | AI 按钮重新变灰，不可点击 |
| 6 | 重复 2，点击 Claude 按钮 | 打开 `claude.ai/new`，剪贴板内容更新为最新 prompt |
| 7 | 切换系统语言到英文，刷新 demo.html，再次点书签 | 按钮上方的标题显示 "Open in AI tool" |
| 8 | Chrome 启用"阻止弹出窗口"，点击 ChatGPT | 仍能打开（因为是用户手势触发） |
