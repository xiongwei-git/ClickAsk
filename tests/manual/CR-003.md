# CR-003 手动测试

环境：Chrome DevTools 控制台 + demo.html。

| # | 步骤 | 预期 |
|---|------|------|
| 1 | demo.html 打开 ClickAsk，控制台 `document.querySelectorAll('[data-clickask-id]').length` | 输出 `0` |
| 2 | 点击销售表某行后再查询 | 仅 1（只有被选中行） |
| 3 | 点击关闭按钮再查询 | 输出 `0` |
| 4 | 再次打开 ClickAsk，控制台执行 `window.__t = document.createElement('div'); __t.textContent='dynamic'; __t.style.cssText='padding:8px;background:#fffaf2;border:1px solid #ccc;margin:8px'; document.querySelector('main').appendChild(__t)` 后点击该 div | 该元素可被选中（出现红框） |
| 5 | 选中一个元素后，控制台 `__t.remove(); window.dispatchEvent(new Event('scroll'))` | 该元素的红框 overlay 消失 |
| 6 | 大列表场景：在 chrome devtools Performance 录制启动 ClickAsk 的 100ms | 不再有大段 setAttribute 占用 |
