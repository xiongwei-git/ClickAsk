# CR-007 手动测试用例

## 准备

1. 一次性获取 vendor 文件（仅首次）：

   ```sh
   curl -fsSL https://unpkg.com/html2canvas@1.4.1/dist/html2canvas.min.js \
     -o assets/vendor/html2canvas.min.js
   ```

2. 启动本地 HTTP 服务：

   ```sh
   python3 -m http.server 18082
   ```

3. 浏览器打开 `http://localhost:18082/`，拖 ClickAsk 到书签栏。

## 用例 1：本地 demo.html 正常截图

| 步骤 | 预期 |
|------|------|
| 打开 demo.html，点书签激活 | 面板出现 |
| 点击页面中任意元素（如 h1） | tag 内可见 📷 按钮 |
| 点 📷 | status 显示「正在加载截图库…」→「截图中…」 |
| 短时间后 | tag 下方出现 thumbnail（带「下载」链接和「✕」按钮） |
| 展开 Prompt 预览 | 含 `截图: [WxH PNG attached via clipboard image]` 行 |

## 用例 2：vendor 文件缺失（lazy load 失败路径）

| 步骤 | 预期 |
|------|------|
| 删除 `assets/vendor/html2canvas.min.js` | - |
| 重新激活 ClickAsk，点 📷 | status 先显示「加载中」，几秒后显示「截图失败：…」 |
| 检查 console | 应有 `assets/vendor/html2canvas.min.js 404` |

## 用例 3：跨域元素

| 步骤 | 预期 |
|------|------|
| 浏览到一个含跨域 `<img>` 的页面（如 wikipedia 词条页） | - |
| 选中含图的区域 → 点 📷 | status 显示「该区域含跨域资源，无法截图。」 |

## 用例 4：复制 prompt + 粘贴到 ChatGPT 自动附图

| 步骤 | 预期 |
|------|------|
| demo.html，选元素并截图 | thumbnail 出现 |
| 输入 intent 「让这个区域更有层次」 | - |
| 点「复制 Prompt」 | button 文本短暂变「已复制」 |
| 在 ChatGPT 输入框粘贴（Cmd+V） | **既出现 prompt 文本，又自动附上图片** |

注：Safari 可能因 `ClipboardItem` 对 image/png 的限制只粘贴文本，这是预期降级。

## 用例 5：移除截图 / 关闭面板清理

| 步骤 | 预期 |
|------|------|
| 截图 1 → 多选第 2 个元素 → 截图 2 | 出现 2 个 thumbnail |
| 点截图 1 旁的「✕」 | 仅截图 1 消失，截图 2 保留 |
| 点面板右上角 ✕ 关闭 ClickAsk | - |
| 重新激活 ClickAsk | thumbnail 区为空 |
