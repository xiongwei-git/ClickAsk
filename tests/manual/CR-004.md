# CR-004 手动测试

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 全新隐私窗口打开 demo.html → 启动 ClickAsk | 历史区域显示 historyEmpty 文案，无 chip |
| 2 | 选中销售表一行 + 输入"为什么数字下降"+ 点「复制 Prompt」 | 历史区出现 1 个 chip，文本含输入内容截断 |
| 3 | 关闭面板，重启 ClickAsk | chip 仍在（localStorage 持久化） |
| 4 | 点击该 chip 主体 | textarea 自动填入"为什么数字下降"，模板 select 切到当时使用的类型，预览刷新 |
| 5 | 连续复制 6 条不同 intent | 历史区始终最多 5 条，最新置顶 |
| 6 | 重复复制完全相同的 (intent, 模板) | 总条数不增加，被复制的项置顶 |
| 7 | 点击某 chip 右侧的 × | 该条立即从 UI 与 localStorage 移除，刷新后仍不在 |
| 8 | 浏览器隐私模式 / 禁用 localStorage 后再启动 | 不报错，历史区始终显示 historyEmpty |
